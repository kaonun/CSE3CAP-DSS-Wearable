# DSS Wearable

A security-first Bluetooth/NFC wearable companion app, built with Expo Router and TypeScript. Connects to BLE wearables (heart rate, step cadence, and user-defined custom characteristics), identifies devices over NFC, and syncs readings to Firebase with per-user Firestore security rules.

## Prerequisites

- [Node.js](https://nodejs.org) (LTS)
- [Android Studio](https://developer.android.com/studio), with the **Android SDK** and **Android SDK Platform-Tools** components installed
- A physical Android device for testing BLE/NFC (an emulator can't do either)

## Setup

1. **Get the code**

   ```bash
   git clone https://github.com/kaonun/CSE3CAP-DSS-Wearable.git
   cd CSE3CAP-DSS-Wearable
   ```

   Use a short path with no spaces (e.g. `C:\dev\DSS-wearable`) — deeply nested Android build paths on Windows can hit path-length limits under something like `Desktop\My Project Folder`.

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Add your `.env` file**

   Copy `.env.example` to `.env` and fill in the real values. **Never commit `.env`** — it's gitignored on purpose. Ask a team member for the current values (Firebase config + Google Sign-In client IDs), since they're tied to the shared Firebase/Google Cloud project and shouldn't be pasted into any commit, issue, or public channel.

4. **Generate the native Android project**

   ```bash
   npx expo prebuild --platform android
   ```

5. **Set up Google Sign-In for your machine**

   Google Sign-In on Android is tied to the SHA-1 fingerprint of whatever key signs your build. Every developer's machine generates its own unique debug key, so each new machine needs a one-time step:

   - Either **ask a team member for their `android/app/debug.keystore`** and drop it in at that same path in your project (simplest — you'll share their signing identity, so no extra setup needed), **or**
   - Generate your own and register it:
     ```bash
     keytool -list -v -keystore android/app/debug.keystore -alias androiddebugkey -storepass android -keypass android
     ```
     Take the SHA-1 shown and add it in [Google Cloud Console](https://console.cloud.google.com) → APIs & Services → Credentials → the Android OAuth client, as an *additional* fingerprint (this doesn't remove anyone else's).

   Everything else (email/password sign-in, Firestore sync, History, BLE, NFC) works without this step — it only affects the "Continue with Google" button.

6. **Check `android/local.properties`**

   Should contain one line pointing at your Android SDK install (Android Studio → Settings → Languages & Frameworks → Android SDK shows the path):

   ```
   sdk.dir=C:\\Users\\<you>\\AppData\\Local\\Android\\Sdk
   ```

   This file is gitignored and regenerated by `expo prebuild --clean`, so you may need to re-add it after a clean prebuild.

7. **Connect a device and build**

   Enable Developer Options + USB debugging on your phone, plug it in, then:

   ```bash
   npx expo run:android
   ```

   First build takes a few minutes. After that, `npx expo start` plus Fast Refresh is enough for most day-to-day changes — only structural native changes (new native modules, permissions, app.json config) need a full rebuild.

## Security notes

- Firestore access is scoped per-user under `users/{uid}/...` — see [`firestore.rules`](./firestore.rules). If you change the data schema, the rules need updating and republishing (Firebase Console → Firestore → Rules) to match, or writes will be silently rejected.
- `.env` and anything matching `*.jks`/`*.p12`/`*.key`/`*.pem` are gitignored — keep it that way.
